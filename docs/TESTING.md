# Testing

How quality is enforced before production deploys.

Full test file map: [tests/README.md](../tests/README.md).

## Overview

| Layer | Tool | Location |
| --- | --- | --- |
| Unit + integration | Vitest | tests/unit/ |
| Browser + a11y | Playwright | tests/register.spec.ts |
| Coverage gate | Istanbul | 85% per metric, globally and per functional area ([scripts/coverage-policy.mjs](../scripts/coverage-policy.mjs)) |
| CI | GitHub Actions | .github/workflows/ci.yml |

## Commands

```bash
npm run test:unit              # all Vitest tests
npm run test:unit:coverage     # with coverage report; fails below thresholds
npm run test:coverage:check    # per-area table (also merges Playwright coverage if present)
npm run test:e2e               # Playwright (dev server)
PLAYWRIGHT_USE_BUILD=true npm run test:e2e   # against production build (CI path)
```

## Coverage policy

[scripts/coverage-policy.mjs](../scripts/coverage-policy.mjs) is the single source of truth, used by both `vitest.config.ts` and `scripts/check-coverage.mjs`.

- **Minimum:** 85% statements, branches, functions, and lines.
- **Scope:** all of `src/`, `shared/`, `convex/`, and `security/`, including files no test imports (they count as 0%, not as skipped).
- **Per-area gates:** each functional area must meet the minimum on its own, so well-tested utilities cannot mask an untested workflow.

| Functional area | Paths |
| --- | --- |
| Shared validation, drafts, and error mapping | `shared/**` |
| Backend (Convex queries, mutations, HTTP, email) | `convex/**` |
| Security headers | `security/**` |
| Authentication UI and session | `src/pages/SignIn/**`, `src/hooks/**`, auth components, `src/constants/mockAuth.ts` |
| Registration UI | `src/pages/Register/**` |
| Profile UI | `src/pages/Profile/**` |
| App shell and presentation | `src/main.tsx`, `src/pages/HomeRedirect.tsx`, `src/convex/**`, remaining constants and presentational components |

**Exclusions.** Only generated code, declarations, configuration, and static data are excluded:

| Path | Reason |
| --- | --- |
| `**/*.d.ts` | Type declarations: no runtime code. |
| `convex/_generated/**` | Generated by `convex dev` codegen (or the local server stub). |
| `convex/auth.config.ts` | Deployment configuration read by the Convex platform, not executed by app code. |
| `convex/crons.ts` | Declarative cron schedule; the scheduled mutation (`resumeUploads:cleanupExpiredUploadSessions`) is tested directly. |
| `shared/registration/countries.ts` | Static data generated by `scripts/generate-countries.mjs`. |
| `shared/registration/mlhSchools.ts` | Static data generated by `scripts/generate-mlh-schools.mjs`. |

To add an exclusion, add it to `COVERAGE_EXCLUDE_REASONS` with a reason, and add a row to this table.

In CI, the **quality** job fails if any threshold is missed. It then writes a per-area coverage table to the job summary and uploads the HTML/LCOV report as the `unit-coverage` artifact.

Unit tests never contact live services: Convex functions run in `convex-test`, and the Convex client, auth hooks, and `fetch` (including the email service, via `tests/unit/setup.ts`) are mocked.

Convex tests use `convex-test` with `import.meta.glob` over `convex/**/*.ts`. Local runs copy a server stub via scripts/ensure-convex-server-stub.mjs when `convex/_generated/` is absent.

## E2E tests

Playwright covers password sign-up, mock OTP verify, registration UI, profile layout/sign-out, and CSP header assertions (`register.spec.ts`, `profile.spec.ts`). Contact form tests remain in hackuta-2026-registration.

CI builds with `VITE_USE_MOCK_API=true` — no live Convex or email service in browser jobs.

## CI pipeline

| Job | Steps |
| --- | --- |
| **quality** | lint → typecheck → unit tests + coverage → production build |
| **e2e** | Playwright against uploaded dist/ artifact |
| **dependency-audit** | npm audit --omit=dev --audit-level=high |
| **secrets** | Gitleaks full-history scan |

## Writing tests

- **Validation changes:** add cases to the matching shared/ unit test; server must stay in sync with client schema.
- **HTTP upload changes:** extend convex.test.ts resume section; use `X-Test-Content-Length` + `X-Test-Origin` (convex-test cannot set Content-Length).
- **CSP changes:** update security/csp.ts **and** vercel.json; security.test.ts enforces parity.
- **New public API:** document in [API.md](API.md) and add convex-test coverage where applicable.

## Mock mode

`VITE_USE_MOCK_API=true` bypasses Convex Auth and mutations. Mock OTP: **042681**. Used in CI e2e, not production.
